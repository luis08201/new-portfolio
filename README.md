# Portafolio de Luis Selva

Página del portafolio: presentación, tres piezas de trabajo, una selección de práctica y un formulario de contacto (Formspree). Es HTML, CSS y JavaScript sin paso de compilación, así que GitHub Pages la sirve tal cual.

En línea: https://luis08201.github.io/new-portfolio/

- `index.html`: contenido de la página
- `css/style.css`: estilos
- `js/main.js`: validación y envío del formulario
- `img/`: retrato y capturas de los proyectos

## Verla en local

Abre la carpeta con cualquier servidor estático, por ejemplo:

```bash
npx serve .
```
