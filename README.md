# Portafolio de Luis Selva

Página del portafolio con diseño bento: presentación, proyectos, 34 retos de Frontend Mentor filtrables por nivel, recorrido y formulario de contacto (Formspree). Es HTML, CSS y JavaScript sin paso de compilación, así que GitHub Pages la sirve tal cual.

En línea: https://luis08201.github.io/new-portfolio/

- `index.html`: contenido de la página
- `css/style.css`: estilos
- `js/main.js`: formulario, filtros de retos y animaciones
- `js/vendor/`: GSAP 3.15 (núcleo, ScrollTrigger, Flip, DrawSVG y SplitText)
- `img/`: retrato y capturas de los proyectos y retos

Las animaciones se desactivan cuando el sistema pide reducir el movimiento, y el contenido se muestra igual si GSAP no carga.

## Verla en local

Abre la carpeta con cualquier servidor estático, por ejemplo:

```bash
npx serve .
```
